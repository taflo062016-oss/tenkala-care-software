    TENKALA CARE SOFTWARE

    User manual: getting started and everyday use

    Health facility management software · designed, checked and approved by NKENLIFACK Florent Tasso' Ndombou · produced with the assistance of Claude (Anthropic’s AI) · built and distributed via GitHub.

    Contents

      1. Overview and principles

      TENKALA CARE SOFTWARE brings together the management of a health centre in a single program: patients, consultations, care, laboratory, pharmacy, cash desk, staff, logistics, immunisation, medical reference material, telemedicine and reporting to MINSANTÉ (Ministry of Public Health).

      Key points

      • Offline: the software works without internet. Internet is needed only for updates, DHIS2, telemedicine (Synapse), the AI assistant and web searches.
      • Data stays on the device on which it is entered. Each computer or phone has its own data: it is moved by backup and restore (chapter 16).
      • Each user has an account (name + PIN code) and sees only the modules authorised for their role.
      • Everything is recorded in the activity log.

      2. Installation and updates

      Installing on a Windows computer

      1. On the software’s GitHub site, open Releases and download the file TENKALA-CARE-SOFTWARE-Installation-x.x.x.exe.
      2. Run it, choose the installation folder and confirm. A shortcut is created on the desktop.
      3. When it starts for the first time, create the administrator account (chapter 3).

      Installing on a phone

      1. In Chrome (Android) or Safari (iPhone), open the address of the online software, starting with https://.
      2. Android: menu ⋮ › Install app. iPhone: Share › Add to Home Screen.
      3. Open it once with internet; after that it works offline.

      Updates

      The Windows version checks for updates by itself 10 seconds after start-up and then every 6 hours. When a new version is ready, a window offers Restart now or Later (installed when the program closes). You can also start the check from File › About › Check for updates, which also shows the installed version and the date of the last update.

      Manual updates

      The manual comes with the software and follows its updates. Between two versions, a corrected edition may be published online: each time the software starts with internet, it downloads it and keeps it for offline use. The edition reference is shown at the top of the contents.

      TipMake a backup (.json) before accepting an update. Your data is kept, but a safety copy is always wise.

      3. First start, logging in and roles

      Creating the first administrator

      1. Click Create the administrator account.
      2. Enter the full name and a PIN code (twice). Remember it: it cannot be recovered.
      3. Then enter the centre’s details (chapter 4).
      ImportantFor DÉÏ GRACIA Health Centre, the first administrator must be exactly “Florent Tasso' Ndombou”. Otherwise the software switches to generic mode and removes the information specific to DÉÏ GRACIA (identity, printable forms, booklets).

      Reading the manual before logging in

      The manual can be printed or downloaded as a PDF or as an HTML page from its window.

      On the login screen, the 📘 User manual button opens this manual without logging in: ideal for the theoretical training of new staff. Once logged in, it remains available from the 📘 Manual icon on the toolbar and from the Help menu.

      Logging in and out

      Choose your name, enter your PIN and confirm. Your name and role are shown in the box on the right of the toolbar. The red ⏻ Exit button ends the session: always use it before leaving the workstation. The Show the PIN code box, under each code field (login, account creation, AI Assistant key), shows what you type; the code is hidden again as soon as the form is sent. Do not use it if someone can see the screen.

      Creating other accounts

      On the login screen, Create a new account: an administrator account (two at most) is created without further approval; a user account must be approved by one of the administrators, who chooses their name and types their PIN code.

      Patients registered before this version keep their old code (P00001…); an administrator can give them the MINSANTÉ code with the MINSANTÉ codes for existing patients button in the patient list. The old code remains visible and can still be used to search.

      Roles

      Each role (Administrator, Doctor, Nurse, Midwife, Laboratory technician, Pharmacist, Cashier, Human resources, Reception, Logistics, etc.) gives access to a set of modules. The administrator creates the accounts and adjusts access rights in Tools › Users and access rights.

      4. Setting up the centre

      1. Tools › Settings: name of the centre, motto, address, town, telephone, e-mail, person in charge and their position, logo.
      2. This information appears on the toolbar and in the header and footer of every printed document (with the QR code).
      3. Tools › Users and access rights: create one account per staff member with the right role.
      4. Pharmacy: create the product catalogue (chapter 8). Staff: enter the employees (chapter 10).
      5. Tools › Interface configuration (administrator): labels, hidden modules, drop-down lists, notice shown at the top, loading a configuration file (.json).

      Customising the toolbar

      • Hide a button: right-click the button › 🙈 Hide from the toolbar.
      • Add a module: right-click a module in a drop-down menu or a tile on the home page › 📌 Show in the toolbar.
      • Show it again: right-click an empty part of the bar › choose the button to show again, or ↺ Restore the default toolbar.
      • Each user keeps their own toolbar on the device.

      Moving and resizing windows

      • Move: grab the title bar (central window, data entry windows) or the “Dashboard” header of the side panel, and drag.
      • Resize: drag an edge (left, right, bottom) or a corner. The content adapts: single-column forms, scrolling tables, nothing is hidden.
      • No overlapping: the central window and the side panel never overlap; a window stops at the edge of the other. To make room, first shrink the other window.
      • Quick fit: double-click an edge (left, right, bottom) or a corner: the window extends in that direction up to the neighbouring window or to the edge of the screen.
      • Reset: double-click a title bar. Data entry windows (dialog boxes) stay in front.

      Home (all modules)

      The Home button shows all the round tiles, sorted by group. Click a tile to open the module.

      Display

      Display lets you choose the colours (theme) and, on a phone, the “desktop version”.

      End-of-year holiday theme

      From 20 December to 31 January every year, the software takes on a festive look by itself: a Santa hat on the logos, a string of lights under the menu bar, red and green colours, gently falling snowflakes and stars, and a greeting on the home page and dashboard (for example, from 20 December 2026 to 31 January 2027: “Merry Christmas 2026 and a Happy New Year 2027.”). The Holidays button in Display (also on the login screen) switches between auto, on and off; the ❄ Snowflakes button turns off only the snowflakes. The choice is specific to each device; nothing appears in print.

      Button conventions

      Solid green button: main action (Save, Approve). White button with a green border: secondary action (Cancel, Print). Red button: deletion or exit. Fields marked * are required.

      6. Patients and care pathway

      Registering a patient

      1. Toolbar › Patient (or Reception and care › Patient registration).
      2. Enter the surname, first name, sex, date of birth, mother’s full name and mother’s patient code (if she has one), telephone and address. When you type a surname or first name, the software suggests only names already registered (patients and staff); for the mother, it suggests women already registered and then fills in her patient code automatically. Each suggestion list only offers items of the same kind as the field (no products or diseases in a person’s name). As soon as a patient is selected in a form, their details (code, sex, age, telephone, mother, allergies) appear under the field; the same applies to an employee (staff number, position, hiring and contract end dates). The age is calculated from the date of birth and today’s date (in days for a newborn, in months under 2 years, in years and months up to 5 years).
      3. The patient code follows the MINSANTÉ registers: reversed date of birth (YYMMDD), initials of the surname and first name, a hyphen, and the initial of the mother’s name. Example: born 25/03/2013, TCHOUPO Clarisse, mother MBARGA → 130325TC-M. The code is shown while you type and is updated if the record is corrected.
      4. Child without an own code: choose “Child: mother’s code + year of birth”, then enter the mother’s patient code (or select her among the centre’s patients); the code becomes the mother’s code followed by the last two digits of the year of birth (e.g. 950704NA-E/26). Identical codes are distinguished by “.2”, “.3”, etc.
      5. Save. To find a patient, type their name or code in the toolbar search box.
      6. In every form that asks for a Patient (health check-up, consultation, invoice, etc.), click in the field: the list of registered patients appears; type a few letters of the name or code to narrow it, then click the patient.

      Patient record

      The record brings together the identity, consultations, tests, prescriptions, hospital stays, invoices and the Synapse (telemedicine) box. The buttons at the top of the record start each procedure.

      Consultation

      1. Toolbar › Consultation, then choose the patient.
      2. Enter vital signs, reason for consultation, examination findings and diagnosis. In the diagnosis field, type a few letters: ICD-11 titles and codes are suggested if ICD-11 has been imported (chapter 13).
      3. Add prescriptions and test requests, then save. The prescription and other documents are printed from the consultation.

      Other care services

      Depending on access rights: Appointments, Health checks, Emergency department, Treatment room, Day hospital, Hospitalisation (admission, follow-up, discharge, discharge summary), Nursing station, Operating theatre, Physiotherapy, Medical opinions, Medical records. They all work the same way: + New button, form, save, filterable list.

      7. Technical facilities

      Laboratory: tests requested during a consultation appear in the list of requests. The laboratory technician records the samples and then the results; the status changes to “Done” and the result can be printed.

      Laboratory module

      Open it from Technical services › Laboratory or the Test toolbar button. It has four tabs:

      1. 🔒 Test list — opens only with an administrator’s password; three columns: ① the benches (Haematology, Biochemistry, Parasitology, Serology / Immunology, Bacteriology), ② the tests of the selected bench, ③ the test sheet: usual specimen, parameters according to the expected result type, then price. Nothing is kept until ✔ Save the test. For a multi-parameter test (FBC…), a window sets the normal values: general, and if needed male, female, male and female aged 50 and over, child (under 15), newborn, with the interpretation word (e.g. Anaemia).
      2. Test requests — choose the patient, prescriber and clinical information, then add tests with drop-down lists (bench, then test). For each test, set Accepted or Not accepted (whether the patient agrees to have it done): only accepted tests go to the benches and count in the total; the others stay at the bottom of the request, with an Accept button for later. In the patient record, and in the consultation (below the diagnoses), the 🧪 Test request button opens this window without leaving the screen; from the consultation, the prescriber and diagnoses are carried over. In every window, the ↑ ↓ keys (and Page Up / Page Down) scroll the content.
      3. Bench worklist — tests to perform, filtered by bench, with Enter result: the window includes the receipt or proof-of-payment number (the patient’s invoices are suggested; a warning appears if it is missing); value read and comment per parameter, normal values adapted to sex and age, Low / High and a suggested (editable) interpretation. No comment or interpretation in biochemistry. Missing values are flagged when saving and when closing; if their absence is confirmed, they are not printed. 👁 Result preview shows the result before saving.
      4. Results and reports — results of the same patient released on the same day are combined on a single report, ordered by bench. 👁 Preview (one test) and 👁 Full report preview open with a zoom; Print… uses the software’s page layout (letterhead, footer, A4 or A5, no frame).

      Bacteriology (HVS, MSU, urethral swab, pus, stool culture, semen culture + AST): macroscopy, microscopy, Gram stain, culture on routine media, antibiotic susceptibility; the report prints “item: result”. Serology: quantitative tests (e.g. CRP 0 – 5 mg/L) and rapid tests with a comment; IgG / IgM tests give two lines, without normal values. Normal values follow the centre’s laboratory sheets; the laboratory supervisor adjusts them in the test sheet.

      Imaging, Blood bank, Sterilisation: same principle (request, procedure, result).

      8. Pharmacy and stock

      Product catalogue

      Technical facilities › Pharmacy: add each product (name, strength, dosage form, category, price, alert threshold), one at a time or as a list with Add several products.

      Receipts and issues

      1. + Receipt (delivery): product, quantity, date, batch number, expiry date, supplier.
      2. − Issue: dispensing, use in care, loss, expiry, etc. The toolbar also offers Stock issue.
      3. Sales invoiced at the cash desk are deducted from stock automatically.
      4. Stock-take: enter the quantity counted; the difference is corrected and recorded.
      Supplier invoice read by the AIThe 🤖 Supplier invoice button reads the photo or PDF of an invoice and proposes stock receipt lines for you to check (chapter 15).

      The “products below the threshold” and “batches nearing expiry” alerts appear on the dashboard.

      9. Cash desk, invoicing and finance

      1. Toolbar › Invoice: choose the patient, add the procedures and products, and apply any coverage (insurance).
      2. Take payment (in full or in part) and print the receipt.
      3. Unpaid invoices remain flagged in Finance › Cash desk and invoicing.

      Other screens: Hospital billing, Insurance and coverage, Income and expenditure (accounting, opening balance sheet), Doctors’ fees, Reports (activity and income by period, which can be exported and printed).

      10. Staff

      The Staff menu opens staff management with its tabs: Staff files, Recruitment, Payroll, Documents, Tools.

      Creating an employee file

      1. + New employee, then complete the identity, contract, salary, positions held and successive contracts.
      2. Photo: in “Photo and additional information”, use 🖼️ Choose for an existing photo or 📷 Camera to take one with the computer’s camera (place the face inside the dotted frame, then Capture). It is cropped automatically to 3.5 × 4.5 cm.
      3. With the AI: 🤖 Fill in from documents reads the ID card, birth certificate, diplomas and contract, and fills in the empty fields, highlighted in yellow for checking (chapter 15).
      4. Click Save.

      From the list: File, Payroll, Certificate of service / of employment, Individual record, Professional ID card. Also: contract due dates, recruitment of candidates, leave and absences, on-call rota, payslips and their history.

      Hiring a candidate

      In Recruitment, open the selected application, enter the hiring date (required), then click ✔ Hire: create the employee file. The file opens with this date as the start of the first position and of the probationary period (end calculated at 3 months). The dates can be changed at any time in the file (positions held and successive contracts).

      Hiring and contract end dates

      Each employee file has two fields: Hiring date and Contract end date. No date is filled in automatically any more: enter them yourself. Both dates are used in the certificate of service (“since…”, and “until…” for a fixed-term contract or probation) and in the certificate of employment (“from… to…”). On the Certificate / Attestation screen they appear pre-filled and can be corrected; the Save these dates in the file button updates the file. If a date is missing, a warning is shown and the document displays dotted lines to complete.

      11. Logistics

      Statement of needs (printable forms), Store (non-pharmaceutical items, thresholds), Store movements, Suppliers, Equipment and assets (inventory, warranty, breakdowns), Equipment to acquire, Maintenance, Linen, Catering, Ambulance, Mortuary, Patient feedback.

      12. Immunisation (EPI)

      The Immunisation button opens the module with its own side menu: Dashboard, Immunisation session, Beneficiaries (children, pregnant women, etc.), Recalls and lost to follow-up, Vaccine stock, Cold chain (temperature readings), Campaigns, AEFI, Monthly report, Immunisation schedule, Online update, Settings.

      1. Register the beneficiary, then open a session and tick the doses administered.
      2. The next appointments are calculated according to the EPI schedule; overdue doses appear in Recalls and lost to follow-up.
      3. Record the refrigerator temperature twice a day in Cold chain.
      4. At the end of the month, produce the monthly report.

      The dashboard panel is collapsed in this module to leave more room; click “» Dashboard” to show it.

      13. In/formation, dictionaries and ICD-11

      Library of information sheets

      Tools › In/formation opens the library: common diseases, conditions by theme (18 themes for sub-Saharan Africa), treatment protocols, MINSANTÉ / EPI guidelines, epidemic alerts. The search suggests sheets from the first few letters (“oxy” → oxygen, pinworms, etc.) and offers an internet search if nothing is found. Only administrators create, edit and validate sheets.

      Language of the sheetsIn the English interface, the titles and themes of the sheets are shown in English, but their medical content and the built-in glossary remain in French for this version: they are validated reference texts and will be translated after medical review.

      Underlined medical terms

      Click an underlined term to see its definition. Right-click (computer) or long press (phone) to choose between the built-in dictionary, the sheet, ICD-11 codes, imported dictionaries and the internet. An administrator can select a word and right-click it to add it to the dictionary.

      Images and attachments of a sheet

      1. In the sheet, 📎 Attach an image or a document (administrator): choose one or more files and enter the caption, source and licence.
      2. Images are shown as thumbnails; click to enlarge, move to the next one, or 🖨️ Print the image.
      3. 🔎 Search for free images opens image banks that can be reused (CDC, Wikimedia Commons, WHO, etc.).
      Rights and confidentialityUse only royalty-free images, citing the source, or photos taken at the centre with the patient’s written consent, showing no face or identifying feature.

      ICD-11 (WHO)

      1. Download the ICD-11 “spreadsheet file” in French from the WHO website (Info › Spreadsheet file, .zip file).
      2. Documents › ICD-11 classification › Import (administrator), and choose the .zip file without unzipping it.
      3. From then on, code searches, diagnosis suggestions and the glossary work offline.

      Medical dictionaries

      Documents › Medical dictionaries: import Orphanet (French nomenclature pack, orphacode.org), the WHO Essential Medicines List, or a personal list (Excel file with the columns Terme, Définition, Synonymes – the medical glossary supplied with the software is an example). Their definitions are shown offline in In/formation.

      14. Synapse (telemedicine)

      Before sending anythingObtain the patient’s consent: Consent button, form to complete (the wording adapts to the sex chosen), then print and sign. By default, the patient’s identity is reduced to their initials (Law No. 2024/017).

      Tele-expertise (request for opinion)

      1. From the patient record or Tools › Synapse › New request for opinion: the summary is pre-filled from the last consultation.
      2. Add photos (files or the computer’s camera) and choose the correspondent.
      3. Send by WhatsApp or e-mail; record the reply, then close the request.

      Video teleconsultation

      1. Create the teleconsultation; a video-conference link is generated.
      2. Test the camera and microphone, then send the link to the doctor (WhatsApp or e-mail) and start.
      3. Write the report and, if needed, the prescription; both can be printed.

      Correspondents tab: doctors and specialists with their WhatsApp number and e-mail.

      15. AI Assistant (Windows version)

      Claude, Anthropic’s AI, reads documents (photos or PDFs) and pre-fills the software. Internet is needed while reading, and each reading has a cost (a few FCFA per page).

      Setting up (administrator)

      1. Create an account on platform.claude.com, add credit and set a monthly spending limit.
      2. Create an API key (“Create key”) and copy it.
      3. Tools › AI Assistant › Key, settings and log tab: paste the key, click Save the key, then Test.
      Key securityThe key is a password linked to your paid account. It is encrypted by Windows and stays on the computer. Never share it with anyone, never put it on GitHub or in a message. If in doubt, delete it in the Anthropic Console and create a new one.

      The “AI Assistant” workspace (Tools › AI Assistant)

      1. Documents: 📂 Choose from the computer (photos or PDFs) and/or 📷 Take with the camera: the computer’s camera, a phone used as a USB webcam, or photos sent over Wi-Fi (chapter 21). Up to 12 pages; ✕ removes a page.
      2. Processing tool: Sonnet 5.5 (recommended, photos and handwriting), Haiku 5.5 (economical, clear typed documents) or Opus 5.5 (most accurate, damaged documents). The estimated cost per page is shown.
      3. Form to complete: New employee file, New patient (identity), Supplier invoice → stock receipt, or Any other form in the software.
      4. Tick the consent of the person concerned, then 🤖 Read and fill in the record. The form opens pre-filled; the fields filled in are highlighted in yellow. Check, correct, then save.

      Filling in any form

      All the standard forms in the software (appointment, supplier, equipment, leave, consultation, etc.) have a 🤖 Fill in with the AI button at the bottom of their window (Windows version). Load the documents or photograph them, tick the consent box, then Read and fill in: only empty fields are completed, and values already entered are never replaced. Documents loaded in the workspace are included automatically.

      Shortcuts

      • Employee file: 🤖 Fill in from documents in the file.
      • Supplier invoice: Pharmacy › Stock › 🤖 Supplier invoice.
      Golden ruleThe AI can get a figure or a name wrong: always read through before saving. The assistant’s log shows each reading and its estimated cost.

      16. Backup, transfer and data security

      Backing up

      1. Toolbar › Back up (or File › Back up the data): a .json file is created.
      2. Store it on a USB stick or other storage medium, at least once a week and before every update.

      Restoring or moving to another device

      File › Open a backup (administrator): choose the .json file. Warning: restoring replaces the data on the device. For a phone, send yourself the file (WhatsApp, cable), save it, then restore it in the app.

      Imported files (Windows version)

      Sheet images, Synapse photos, ICD-11 and dictionaries are copied automatically to Documents\TENKALA CARE SOFTWARE\Fichiers. If the internal copy disappears, the software recovers it from this folder. The path and an “Open the folder” button are shown in File › About. Include this folder in your backups. Sheet images can also be exported and imported from In/formation › Data and images.

      ConfidentialityBackups contain health data. Do not leave them in WhatsApp or a mailbox after use; protect the USB stick; give each staff member a personal PIN code; end the session (Exit) when leaving the workstation.

      18. Documents and forms

      Documents: Management documents (templates to complete), Forms to print, Booklet production. Documents open as an A4 or A5 preview with the letterhead, the title below the rule, a footer with the centre’s contact details and a QR code; use Print or Download (PDF).

      The certificate of service (employee in post) and the certificate of employment (employee who has left the centre) are in Management documents › Staff: choose the employee and the document is filled in from their file (identity, position, dates, contract).

      The partograph in the ANC booklet follows the current WHO model: 12 hours divided into 30-minute intervals (two columns per hour), an alert line from 4 to 10 cm over 6 hours and an action line 4 hours later, with “number of hours” and “actual time” rows.

      20. Good daily practice

      • In the morning: log in, check the Dashboard panel (appointments, stock and contract alerts), record the vaccine refrigerator temperature.
      • During the day: enter data as you go; one session per staff member; check the patient’s identity before any procedure.
      • In the evening: close the cash desk, make a backup, end the session.
      • Every Monday: MAPE from 9 a.m. Every month: RMA III from the 2nd, EPI report, stock-take.
      • Always: read through what the AI has filled in, respect medical confidentiality and Law No. 2024/017.

      Manual supplied with the software, available offline. To be supplemented with your facility’s own procedures.

      21. Image capture (camera, phone)

      In Tools › AI Assistant, step 1, the 📷 Take with the camera button opens the Image capture panel. Each photo captured or received is added directly to the documents to be read. ✕ Close the capture panel closes the panel and switches the camera off.

      Choosing the camera

      The Connected cameras list shows all the cameras that can be used (💻 built-in, 🎥 USB, 📱 phone used as a webcam). Use shows it live; ★ makes it the default for the whole software (staff photos, Synapse, forms). ⏹ Close camera switches it off; ▶ Open camera switches it on again. The list is updated when a camera is plugged in; otherwise use 🔄 Refresh.

      Phone as a webcam over a USB cable (fixed workstation)

      1. Install DroidCam (or Iriun Webcam) on the phone and its companion program on the computer; use a USB data cable.
      2. On the phone, once only: Settings › About phone › tap Build number 7 times, then Settings › System › Developer options › USB debugging.
      3. Connect the cable, allow debugging, open DroidCam on the phone and then DroidCam Client on the computer (USB button, Start).
      4. In the capture panel, click Use next to the 📱 “DroidCam” camera, then ★. Place the phone on a stand and click 📸 Capture.

      Sending over the local Wi-Fi (photos taken on the move)

      1. In the capture panel, click ▶ Start receiving (Windows version): a QR code is displayed. The first time, allow TENKALA CARE on private networks if Windows asks.
      2. The phone, connected to the same Wi-Fi network, scans the code: a page lets you Take a photo or Choose from the gallery.
      3. The photos arrive immediately in the documents (a copy is kept in Documents\TENKALA CARE SOFTWARE\Fichiers\telephone). Receiving stops automatically after 20 minutes without any sending.

      Patient photos are covered by medical confidentiality: obtain consent, avoid showing the face unless necessary, and remove them once they have been used.

      22. Interface language (French / English)

      TENKALA CARE SOFTWARE can be used in French or in English. The choice is made per device and takes effect immediately (the software reloads; no data is lost).

      1. Before logging in: on the login screen, click 🌐 Français or English under the manual button.
      2. Once logged in: Help › 🌐 Français or Help › 🌐 English.
      What is translatedMenus, buttons, forms, messages, tables, the staff and payroll module, accounting and taxation screens, the immunisation module interface, documents printed from the software’s windows (invoices, certificates, payslips, reports), and this manual. Official PDF forms supplied by the authorities keep their original wording. Medical terms follow WHO usage in British English (e.g. anaemia, haemoglobin, paediatrics, immunisation).
      What stays as enteredData entered by users is stored exactly as typed and is never changed. Free text (names, notes, observations) is shown as typed; standard terms taken from the software’s built-in lists (diagnoses, products, units, statuses) are shown in English. In the English interface, information is stored in the same way as in French, so a backup made in one language can be restored in the other. The content of the In/formation sheets and of the built-in glossary remains in French in this version (validated medical texts).
      Official documentsContracts, certificates and returns follow Cameroonian law (Labour Code, General Tax Code). The English wording is a faithful rendering for bilingual use; if in doubt, the French version issued by the authorities prevails.

      23. Published (campaign documents)

      Documents › Published brings together the documents used for campaigns: posters, leaflets, circulars and memoranda, guides and protocols, reports, technical sheets, presentations, photos and videos. Everyone can consult them; administrators and staff with access to Management documents can publish, edit and delete them.

      Publishing a document

      1. + Publish a document: title, theme (Immunisation, Malaria, HIV / STIs, Nutrition, etc.), type of document, campaign, year, source (MINSANTÉ, WHO, UNICEF, district, etc.), target audience, keywords and description.
      2. 📂 Add files: one or more files (PDF, images, Word, Excel, PowerPoint, video, audio; 50 MB maximum each).
      3. Click Publish. The document appears in the list straight away.

      Finding a document

      The search works as in In/formation: type the first letters of a word in the title, campaign, keywords, source, year or file name (“meas” finds “measles”), without worrying about accents. Several words narrow the search, and the words found are highlighted. The Theme, Type and Year lists filter the results.

      Viewing, downloading, printing

      Click a document to see its details and files. 👁 View opens the file in the software (PDF, images, video, audio); ⭳ Download saves it; 🖨️ Print prints PDFs and images directly. Word, Excel and PowerPoint files are downloaded and then opened with their own program.

      Backing up the filesThe document details are in the general backup (.json), but the files are not. On Windows, they are also copied to Documents\TENKALA CARE SOFTWARE\Fichiers\publies. To move them to another device: ⭳ Export the documents and their files, then, on the other device, ⭱ Import an export.
