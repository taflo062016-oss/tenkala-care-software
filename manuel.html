    TENKALA CARE SOFTWARE

    Manuel de l'utilisateur : prise en main et utilisation au quotidien

    Logiciel de gestion des formations sanitaires · conçu, vérifié et approuvé par NKENLIFACK Florent Tasso' Ndombou · réalisé avec l'assistance de Claude (IA d'Anthropic) · fabriqué et distribué via GitHub.

    Sommaire

      1. Présentation et principes

      TENKALA CARE SOFTWARE réunit dans un seul programme la gestion d'un centre de santé : patients, consultations, soins, laboratoire, pharmacie, caisse, personnel, logistique, vaccination, documentation médicale, télémédecine et rapports au MINSANTÉ.

      Ce qu'il faut retenir

      • Hors ligne : le logiciel fonctionne sans internet. Internet n'est utile que pour les mises à jour, le DHIS2, la télémédecine (Synapse), l'assistant IA et les recherches sur le web.
      • Les données restent sur l'appareil où elles sont saisies. Chaque ordinateur ou téléphone a ses propres données : on les transfère par sauvegarde et restauration (chapitre 16).
      • Chaque utilisateur a un compte (nom + code PIN) et ne voit que les modules autorisés pour son rôle.
      • Tout est tracé dans le journal d'activité.

      2. Installation et mise à jour

      Installer sur un ordinateur Windows

      1. Sur le site GitHub du logiciel, ouvrez Releases et téléchargez le fichier TENKALA-CARE-SOFTWARE-Installation-x.x.x.exe.
      2. Lancez-le, choisissez le dossier d'installation et validez. Un raccourci est créé sur le bureau.
      3. Au premier lancement, créez le compte administrateur (chapitre 3).

      Installer sur un téléphone

      1. Ouvrez dans Chrome (Android) ou Safari (iPhone) l'adresse du logiciel en ligne, en commençant par https://.
      2. Android : menu ⋮ › Installer l'application. iPhone : Partager › Sur l'écran d'accueil.
      3. Ouvrez-la une première fois avec internet ; ensuite elle fonctionne hors ligne.

      Mises à jour

      La version Windows vérifie seule les mises à jour 10 secondes après le démarrage puis toutes les 6 heures. Quand une version est prête, une fenêtre propose Redémarrer maintenant ou Plus tard (installation à la fermeture). Vous pouvez aussi lancer la vérification depuis Fichier › À propos › Rechercher une mise à jour. La version installée et la date de la dernière mise à jour y sont affichées.

      Mise à jour du manuel

      Le manuel est fourni avec le logiciel et suit ses mises à jour. Entre deux versions, une édition corrigée peut être publiée en ligne : à chaque démarrage avec internet, le logiciel la télécharge et la conserve pour la consultation hors ligne. La référence de l'édition est indiquée en haut du sommaire.

      ConseilFaites une sauvegarde (.json) avant d'accepter une mise à jour. Vos données sont conservées, mais une copie de sécurité est toujours prudente.

      3. Premier démarrage, connexion et rôles

      Créer le premier administrateur

      1. Cliquez sur Créer le compte administrateur.
      2. Saisissez le nom complet et un code PIN (deux fois). Retenez-le : il n'est pas récupérable.
      3. Renseignez ensuite l'identité du centre (chapitre 4).
      ImportantPour le Centre de Santé DÉÏ GRACIA, le premier administrateur doit être exactement « Florent Tasso' Ndombou ». Sinon le logiciel passe en mode générique et efface les informations propres à DÉÏ GRACIA (identité, formulaires à imprimer, carnets).

      Consulter le manuel avant de se connecter

      Le manuel peut être imprimé ou téléchargé en PDF ou en page HTML depuis sa fenêtre.

      Sur l'écran de connexion, le bouton 📘 Manuel de l'utilisateur ouvre ce manuel sans identifiant : idéal pour la formation théorique des nouveaux agents. Une fois connecté, il reste accessible par l'icône 📘 Manuel de la barre d'outils et par le menu Aide.

      Se connecter et se déconnecter

      Choisissez votre nom, saisissez votre PIN et validez. Votre nom et votre rôle sont affichés dans le cadre à droite de la barre d'outils. Le bouton rouge ⏻ Quitter ferme la session : faites-le toujours avant de laisser le poste. La case Afficher le code secret, sous chaque champ de code (connexion, création de compte, clé de l'Assistant IA), montre ce que vous tapez ; le code est masqué de nouveau dès l'envoi. Ne l'utilisez pas si quelqu'un regarde l'écran.

      Créer d'autres comptes

      Sur l'écran de connexion, Créer un nouveau compte : un compte administrateur (deux au maximum) se crée sans autre validation ; un compte utilisateur doit être validé par l'un des administrateurs, qui choisit son nom et tape son code secret.

      Les patients enregistrés avant cette version gardent leur ancien code (P00001…) ; un administrateur peut leur attribuer le code MINSANTÉ avec le bouton Codes MINSANTÉ pour les anciens patients de la liste des patients. L'ancien code reste visible et sert toujours à la recherche.

      Rôles

      Chaque rôle (Administrateur, Médecin, Infirmier, Sage-femme, Laborantin, Pharmacien, Caissier, Ressources humaines, Accueil, Logistique…) donne accès à un ensemble de modules. L'administrateur crée les comptes et ajuste les droits dans Outils › Utilisateurs et droits.

      4. Paramétrer le centre

      1. Outils › Paramètres : nom du centre, devise (leitmotiv), adresse, ville, téléphone, e-mail, responsable et sa qualité, logo.
      2. Ces informations apparaissent sur la barre d'outils et dans l'en-tête et le pied de page de tous les documents imprimés (avec le code QR).
      3. Outils › Utilisateurs et droits : créez un compte par agent avec le bon rôle.
      4. Pharmacie : créez le catalogue des produits (chapitre 8). Personnel : saisissez les employés (chapitre 10).
      5. Outils › Configuration de l'interface (administrateur) : libellés, modules masqués, listes déroulantes, annonce affichée en haut, chargement d'un fichier de configuration (.json).

      Personnaliser la barre d'outils

      • Masquer un bouton : clic droit sur le bouton › 🙈 Masquer de la barre d'outils.
      • Ajouter un module : clic droit sur un module dans un menu déroulant ou une vignette de l'accueil › 📌 Afficher dans la barre d'outils.

      Déplacer et redimensionner les fenêtres

      • Déplacer : attrapez la barre de titre (fenêtre centrale, fenêtres de saisie) ou l'en-tête « Tableau de bord » du panneau latéral, et faites glisser.
      • Redimensionner : tirez un bord (gauche, droit, bas) ou un coin. Le contenu s'adapte : formulaires sur une colonne, tableaux défilants, rien n'est masqué.
      • Sans chevauchement : la fenêtre centrale et le panneau latéral ne se superposent jamais ; une fenêtre s'arrête au bord de l'autre. Pour libérer de la place, réduisez d'abord l'autre fenêtre.
      • Ajuster d'un coup : double-clic sur un bord (gauche, droit, bas) ou un coin : la fenêtre s'étend dans ce sens jusqu'à la fenêtre voisine ou jusqu'au bord de l'écran.
      • Remettre en place : double-clic sur une barre de titre. Les fenêtres de saisie (boîtes de dialogue) restent au premier plan.

      Accueil (tous les modules)

      Le bouton Accueil affiche toutes les vignettes rondes, classées par groupe. Cliquez sur une vignette pour ouvrir le module.

      Affichage

      Affichage permet de choisir les couleurs (thème) et, sur téléphone, la « version ordinateur ».

      Thème des fêtes de fin d'année

      Du 20 décembre au 31 janvier, chaque année, le logiciel prend tout seul un air de fête : bonnet de Père Noël sur les logos, guirlande lumineuse sous la barre de menus, couleurs rouge et vert, flocons et étoiles qui tombent doucement, et un message de vœux sur l'accueil et le tableau de bord (par exemple, du 20 décembre 2026 au 31 janvier 2027 : « Joyeux Noël 2026 et Bonne et heureuse année 2027. »). Le bouton Fêtes d'Affichage (aussi sur l'écran de connexion) passe de auto à activé puis désactivé ; le bouton ❄ Flocons coupe seulement les flocons. Le choix est propre à chaque appareil ; rien n'apparaît à l'impression.

      Conventions des boutons

      Bouton vert plein : action principale (Enregistrer, Valider). Bouton blanc à bord vert : action secondaire (Annuler, Imprimer). Bouton rouge : suppression ou sortie. Les champs marqués * sont obligatoires.

      6. Patients et parcours de soins

      Enregistrer un patient

      1. Barre d'outils › Patient (ou Accueil et soins › Enregistrement des patients).
      2. Saisissez nom, prénom, sexe, date de naissance, nom complet de la mère et code patient de la mère (s'il existe), téléphone, adresse. En tapant un nom ou un prénom, le logiciel propose uniquement les noms et prénoms déjà enregistrés (patients et personnel) ; pour la mère, il propose les femmes déjà enregistrées et remplit alors son code patient tout seul. Chaque liste de suggestions ne propose que des éléments du même genre que le champ (pas de produits ni de maladies dans un nom de personne). Dès qu'un patient est choisi dans un formulaire, sa fiche (code, sexe, âge, téléphone, mère, allergies) s'affiche sous le champ ; de même pour un employé (matricule, poste, dates d'embauche et de fin de contrat). L'âge est calculé à partir de la date de naissance et de la date du jour (en jours pour un nouveau-né, en mois avant 2 ans, en ans et mois jusqu'à 5 ans).
      3. Le code patient suit les registres du MINSANTÉ : date de naissance inversée (AAMMJJ), initiales du nom et du prénom, tiret, initiale du nom de la mère. Exemple : née le 25/03/2013, TCHOUPO Clarisse, mère MBARGA → 130325TC-M. Le code s'affiche pendant la saisie et se met à jour si l'on corrige la fiche.
      4. Enfant sans code propre : choisissez « Enfant : code de la mère + année de naissance », puis indiquez le code patient de la mère (ou choisissez-la parmi les patients du centre) ; le code devient celui de la mère suivi des deux derniers chiffres de l'année de naissance (ex. 950704NA-E/26). Deux codes identiques sont distingués par « .2 », « .3 »…
      5. Enregistrez. Pour retrouver un patient, tapez son nom ou son code dans la recherche de la barre d'outils.
      6. Dans tous les formulaires qui demandent un Patient (bilan de santé, consultation, facture, etc.), cliquez dans le champ : la liste des patients enregistrés s'affiche ; tapez quelques lettres du nom ou du code pour la réduire, puis cliquez sur le patient.

      Dossier du patient

      Le dossier regroupe l'identité, les consultations, examens, prescriptions, hospitalisations, factures et l'encadré Synapse (télémédecine). Les boutons en haut du dossier permettent de lancer chaque acte.

      Consultation

      1. Barre d'outils › Consultation, choisissez le patient.
      2. Renseignez constantes, motif, examen, diagnostic. Dans le champ diagnostic, tapez quelques lettres : les libellés et codes CIM-11 sont proposés si la CIM-11 a été importée (chapitre 13).
      3. Ajoutez prescriptions et examens demandés, puis enregistrez. Ordonnance et documents s'impriment depuis la consultation.

      Autres services de soins

      Selon les droits : Rendez-vous, Bilans de santé, Urgences, Salle de soins, Hôpital de jour, Hospitalisation (admission, suivi, sortie, résumé de sortie), Poste de soins infirmiers, Bloc opératoire, Kinésithérapie, Avis médicaux, Archives médicales. Tous suivent le même principe : bouton + Nouveau, formulaire, enregistrement, liste filtrable.

      7. Plateau technique

      Laboratoire : les examens demandés en consultation arrivent dans la liste des demandes. Le laborantin saisit les prélèvements, puis les résultats ; le statut passe à « Fait » et le résultat s'imprime.

      Module Laboratoire

      Le module s’ouvre par Plateau technique › Laboratoire ou le bouton Examen de la barre d’outils. Il comporte quatre onglets :

      1. 🔒 Liste des examens — ouverte uniquement avec le mot de passe d’un administrateur ; trois colonnes : ① les paillasses (Hématologie, Biochimie, Parasitologie, Sérologie / Immunologie, Bactériologie), ② les examens de la paillasse choisie, ③ la fiche d’examen : échantillon habituel, paramètres selon le type de résultat attendu, puis prix. Rien n’est gardé avant le bouton ✔ Enregistrer l’examen. Pour un examen à plusieurs paramètres (NFS…), une fenêtre règle les valeurs normales : générales, et si besoin homme, femme, homme et femme de 50 ans et plus, enfant (moins de 15 ans), nouveau-né, avec le mot de l’interprétation (ex. Anémie).
      2. Demandes d’examen — choisir le patient, le prescripteur, les renseignements cliniques, puis ajouter les examens par listes déroulantes (paillasse, puis examen). Pour chaque examen, indiquez Accepté ou Non accepté (le patient accepte ou non de le faire) : seuls les examens acceptés partent sur les paillasses et comptent dans le total ; les autres restent en bas de la demande, avec un bouton Accepter pour plus tard. Dans la fiche du patient, et dans la consultation (sous les diagnostics), le bouton 🧪 Demande d’examen ouvre cette fenêtre sans quitter l’écran ; depuis la consultation, le prescripteur et les diagnostics sont repris. Dans toutes les fenêtres, les touches ↑ ↓ (et Page préc. / Page suiv.) font défiler le contenu.
      3. Travail par paillasse — examens à faire, filtrés par paillasse, avec Saisir le résultat : la fenêtre comporte le n° du reçu ou de la preuve de paiement (les factures du patient sont proposées ; un avertissement s’affiche s’il manque) ; valeur lue et commentaire par paramètre, valeurs normales adaptées au sexe et à l’âge, Bas / Élevé et interprétation proposée (modifiable). En biochimie, ni commentaire ni interprétation. Les valeurs non renseignées sont signalées à l’enregistrement et à la fermeture ; si leur absence est confirmée, elles ne s’impriment pas. Le bouton 👁 Aperçu du résultat montre le résultat avant de l’enregistrer.
      4. Résultats et bulletins — les résultats d’un même patient rendus le même jour sont réunis sur une seule fiche, rangée par paillasse. 👁 Aperçu (un examen) et 👁 Aperçu de la fiche complète s’ouvrent avec un zoom ; Imprimer… reprend la mise en page du logiciel (en-tête, pied de page, A4 ou A5, sans cadre).

      Bactériologie (PCV, ECBU, PU, Pus, Coproculture, Spermoculture + ATB) : macroscopie, microscopie, coloration de Gram, culture sur milieu usuel, antibiogramme ; la fiche imprime « élément : résultat ». Sérologie : examens chiffrés (ex. CRP 0 – 5 mg/L) et TDR à commentaire ; les examens IgG / IgM donnent deux lignes, sans valeurs normales. Les valeurs normales reprennent les fiches du laboratoire du centre ; le responsable du laboratoire les ajuste dans la fiche d’examen.

      Imagerie, Banque de sang, Stérilisation : mêmes principes (demande, réalisation, résultat).

      8. Pharmacie et stock

      Catalogue des produits

      Plateau technique › Pharmacie : ajoutez chaque produit (nom, dosage, forme, catégorie, prix, seuil d'alerte), un par un ou en liste avec Ajouter plusieurs produits.

      Entrées et sorties

      1. + Entrée (réception) : produit, quantité, date, numéro de lot, date de péremption, fournisseur.
      2. − Sortie : dispensation, utilisation en soins, perte, péremption… La barre d'outils propose aussi Sortie stock.
      3. Les ventes facturées en caisse sortent automatiquement du stock.
      4. Inventaire : saisissez la quantité comptée ; l'écart est corrigé et tracé.
      Facture fournisseur lue par l'IALe bouton 🤖 Facture fournisseur lit la photo ou le PDF d'une facture et propose les lignes d'entrée en stock à vérifier (chapitre 15).

      Les alertes « produits sous le seuil » et « lots proches de la péremption » apparaissent sur le tableau de bord.

      9. Caisse, facturation et finances

      1. Barre d'outils › Facture : choisissez le patient, ajoutez les actes et produits, appliquez une éventuelle prise en charge (assurance).
      2. Encaissez (totalement ou partiellement) ; imprimez le reçu.
      3. Les factures impayées restent signalées dans Finances › Caisse et facturation.

      Autres écrans : Facturation hospitalisation, Assurances et prises en charge, Recettes et dépenses (comptabilité, bilan d'ouverture), Honoraires des médecins, Rapports (activité et recettes par période, exportables et imprimables).

      10. Personnel

      Le menu Personnel ouvre la gestion du personnel avec ses onglets : Dossiers du personnel, Recrutement, Paie, Documents, Outils.

      Créer le dossier d'un employé

      1. + Nouvel employé, puis remplissez l'identité, le contrat, le salaire, les postes occupés et les contrats successifs.
      2. Photo : dans « Photo et informations complémentaires », 🖼️ Choisir une photo existante ou 📷 Caméra pour la prendre avec la caméra de l'ordinateur (placez le visage dans le cadre pointillé, puis Capturer). Recadrage automatique au format 3,5 × 4,5 cm.
      3. Avec l'IA : 🤖 Remplir à partir des documents lit la CNI, l'acte de naissance, les diplômes, le contrat et remplit les champs vides, surlignés en jaune pour vérification (chapitre 15).
      4. Cliquez sur Enregistrer.

      Depuis la liste : Dossier, Paie, Attestation / Certificat de travail, Fiche individuelle, Carte professionnelle. Également : échéances des contrats, recrutement des candidats, congés et absences, planning des gardes, bulletins de paie et leur historique.

      Embaucher un candidat

      Dans Recrutement, ouvrez la candidature retenue, saisissez la date d'embauche (obligatoire), puis cliquez sur ✔ Embaucher : créer le dossier employé. Le dossier s'ouvre avec cette date comme début du premier poste et de la période d'essai (fin calculée à 3 mois). Les dates restent modifiables à tout moment dans le dossier (postes occupés et contrats successifs).

      Dates d'embauche et de fin de contrat

      Le dossier de chaque employé comporte deux champs : Date d'embauche et Date de fin de contrat. Aucune date n'est plus inscrite automatiquement : saisissez-les vous-même. Ces deux dates sont reprises dans l'attestation de travail (« depuis le… », et « jusqu'au… » pour un contrat à durée déterminée ou un essai) et dans le certificat de travail (« du… au… »). À l'écran Certificat / Attestation, elles s'affichent pré-remplies et peuvent être corrigées ; le bouton Enregistrer ces dates dans le dossier met le dossier à jour. Si une date manque, un avertissement s'affiche et le document montre des pointillés à compléter.

      11. Logistique

      Expression des besoins (fiches imprimables), Magasin (articles non pharmaceutiques, seuils), Mouvements du magasin, Fournisseurs, Équipements et biens (inventaire, garantie, pannes), Équipements à acquérir, Maintenance, Lingerie, Restauration, Ambulance, Morgue, Avis des patients.

      12. Vaccination (PEV)

      Le bouton Vaccination ouvre le module avec son propre menu latéral : Tableau de bord, Séance de vaccination, Bénéficiaires (enfants, femmes enceintes…), Rappels et perdus de vue, Stock des vaccins, Chaîne du froid (relevés de température), Campagnes, MAPI, Rapport mensuel, Calendrier vaccinal, Mise à jour en ligne, Paramètres.

      1. Enregistrez le bénéficiaire, puis ouvrez une séance et cochez les doses administrées.
      2. Les prochains rendez-vous sont calculés selon le calendrier du PEV ; les retards apparaissent dans Rappels et perdus de vue.
      3. Relevez la température du réfrigérateur deux fois par jour dans Chaîne du froid.
      4. En fin de mois, produisez le rapport mensuel.

      Le panneau du tableau de bord est replié dans ce module pour laisser plus de place ; cliquez sur « » Tableau de bord » pour l'afficher.

      13. In/formation, dictionnaires et CIM-11

      Bibliothèque de fiches

      Outils › In/formation ouvre la bibliothèque : maladies courantes, pathologies par thème (18 thèmes d'Afrique subsaharienne), protocoles, directives MINSANTÉ / PEV, alertes épidémiques. La recherche propose les fiches dès les premières lettres (« oxy » → oxygène, oxyures…) et suggère une recherche internet si rien n'est trouvé. Seuls les administrateurs créent, modifient et valident des fiches.

      Termes médicaux soulignés

      Clic sur un terme souligné : définition. Clic droit (ordinateur) ou appui long (téléphone) : choix entre dictionnaire intégré, fiche, codes CIM-11, dictionnaires importés et internet. Un administrateur peut sélectionner un mot puis faire un clic droit pour l'ajouter au dictionnaire.

      Images et pièces jointes d'une fiche

      1. Dans la fiche, 📎 Joindre une image ou un document (administrateur) : choisissez un ou plusieurs fichiers, indiquez légende, source et licence.
      2. Les images s'affichent en vignettes ; cliquez pour agrandir, passer à la suivante, ou 🖨️ Imprimer l'image.
      3. 🔎 Chercher des images libres ouvre des banques d'images utilisables (CDC, Wikimedia Commons, OMS…).
      Droits et confidentialitéN'utilisez que des images libres de droits en citant la source, ou des photos prises au centre avec le consentement écrit du patient, sans visage ni élément d'identification.

      CIM-11 (OMS)

      1. Téléchargez le « fichier tableur » de la CIM-11 en français sur le site de l'OMS (Info › Fichier du tableur, fichier .zip).
      2. Documents › Classification CIM-11 › Importer (administrateur), choisissez le .zip sans le décompresser.
      3. Ensuite, recherche de codes, suggestions dans le diagnostic et lexique fonctionnent hors ligne.

      Dictionnaires médicaux

      Documents › Dictionnaires médicaux : importez Orphanet (pack de nomenclature en français, site orphacode.org), la liste OMS des médicaments essentiels, ou une liste personnelle (fichier Excel avec colonnes Terme, Définition, Synonymes – le lexique médical fourni avec le logiciel en est un exemple). Leurs définitions s'affichent hors ligne dans In/formation.

      14. Synapse (télémédecine)

      Avant tout envoiRecueillez le consentement du patient : bouton Consentement, formulaire à compléter (le texte s'accorde au sexe choisi), puis impression et signature. Par défaut, l'identité du patient est réduite à ses initiales (loi n° 2024/017).

      Téléexpertise (demande d'avis)

      1. Depuis le dossier du patient ou Outils › Synapse › Nouvelle demande d'avis : le résumé est pré-rempli à partir de la dernière consultation.
      2. Ajoutez des photos (fichiers ou caméra de l'ordinateur) et choisissez le correspondant.
      3. Envoyez par WhatsApp ou e-mail ; notez la réponse, puis clôturez la demande.

      Téléconsultation vidéo

      1. Créez la téléconsultation ; un lien de visioconférence est généré.
      2. Tester la caméra et le micro, puis envoyez le lien au médecin (WhatsApp ou e-mail) et démarrez.
      3. Rédigez le compte rendu et, si besoin, l'ordonnance, imprimables.

      Onglet Correspondants : médecins et spécialistes avec téléphone WhatsApp et e-mail.

      15. Assistant IA (version Windows)

      Claude, l'IA d'Anthropic, lit des documents (photos ou PDF) et pré-remplit le logiciel. Internet est nécessaire au moment de la lecture, et la lecture a un coût (quelques FCFA par page).

      Mise en service (administrateur)

      1. Créez un compte sur platform.claude.com, ajoutez des crédits et fixez un plafond de dépense mensuel.
      2. Créez une clé API (« Create key ») et copiez-la.
      3. Outils › Assistant IA › onglet Clé, réglages et journal : collez la clé, Enregistrer la clé, puis Tester.
      Sécurité de la cléLa clé est un mot de passe lié à votre compte payant. Elle est chiffrée par Windows et reste sur l'ordinateur. Ne la communiquez à personne, ne la mettez jamais sur GitHub ni dans un message. En cas de doute, supprimez-la dans la Console Anthropic et créez-en une nouvelle.

      L'atelier « Assistant IA » (Outils › Assistant IA)

      1. Documents : 📂 Choisir sur l'ordinateur (photos ou PDF) et/ou 📷 Prendre avec la caméra : caméra de l'ordinateur, téléphone en webcam USB ou photos envoyées par Wi-Fi (chapitre 21). Jusqu'à 12 pages ; ✕ pour retirer une page.
      2. Outil de traitement : Sonnet 5.5 (recommandé, photos et manuscrits), Haiku 5.5 (économique, documents tapés et nets) ou Opus 5.5 (le plus précis, documents abîmés). Le coût estimé par page est affiché.
      3. Fiche à renseigner : Dossier d'un nouvel employé, Nouveau patient (identité), Facture fournisseur → entrée en stock, ou Toute autre fiche du logiciel.
      4. Cochez l'accord de la personne concernée, puis 🤖 Lire et renseigner la fiche. La fiche s'ouvre pré-remplie ; les champs remplis sont surlignés en jaune. Vérifiez, corrigez, puis enregistrez.

      Remplir n'importe quel formulaire

      Tous les formulaires standards du logiciel (rendez-vous, fournisseur, équipement, congé, consultation…) ont un bouton 🤖 Remplir avec l'IA en bas de leur fenêtre (version Windows). Chargez les documents ou photographiez-les, cochez l'accord, puis Lire et remplir : seuls les champs vides sont complétés, les valeurs déjà saisies ne sont jamais remplacées. Les documents chargés dans l'atelier sont repris automatiquement.

      Raccourcis

      • Dossier d'un employé : 🤖 Remplir à partir des documents dans le dossier.
      • Facture fournisseur : Pharmacie › Stock › 🤖 Facture fournisseur.
      Règle d'orL'IA peut se tromper sur un chiffre ou un nom : relisez toujours avant d'enregistrer. Le journal de l'assistant indique chaque lecture et son coût estimé.

      16. Sauvegarde, transfert et sécurité des données

      Sauvegarder

      1. Barre d'outils › Sauvegarder (ou Fichier › Sauvegarder les données) : un fichier .json est créé.
      2. Rangez-le sur une clé USB ou un autre support, au moins une fois par semaine et avant chaque mise à jour.

      Restaurer ou transférer vers un autre appareil

      Fichier › Ouvrir une sauvegarde (administrateur) : choisissez le fichier .json. Attention : la restauration remplace les données de l'appareil. Pour un téléphone, envoyez-vous le fichier (WhatsApp, câble), enregistrez-le, puis restaurez-le dans l'application.

      Fichiers importés (version Windows)

      Images des fiches, photos Synapse, CIM-11 et dictionnaires sont copiés automatiquement dans Documents\TENKALA CARE SOFTWARE\Fichiers. Si la copie interne disparaît, le logiciel la reprend dans ce dossier. Le chemin et un bouton « Ouvrir le dossier » figurent dans Fichier › À propos. Incluez ce dossier dans vos copies de sécurité. Les images des fiches peuvent aussi être exportées et importées depuis In/formation › Données et images.

      ConfidentialitéLes sauvegardes contiennent des données de santé. Ne les laissez pas dans WhatsApp ou une boîte e-mail après usage ; protégez la clé USB ; un code PIN personnel par agent ; fermez la session (Quitter) en quittant le poste.

      21. Prise de vue (caméra, téléphone)

      Dans Outils › Assistant IA, étape 1, le bouton 📷 Prendre avec la caméra ouvre le panneau Prise de vue. Chaque photo capturée ou reçue s'ajoute directement aux documents à lire. ✕ Fermer la prise de vue referme le panneau et coupe la caméra.

      Choisir la caméra

      La liste Caméras connectées affiche toutes les caméras utilisables (💻 intégrée, 🎥 USB, 📱 téléphone en webcam). Utiliser l'affiche en direct ; ★ la choisit par défaut pour tout le logiciel (photos du personnel, Synapse, formulaires). ⏹ Fermer la caméra l'éteint ; ▶ Ouvrir la caméra la rallume. La liste se met à jour quand une caméra est branchée ; sinon 🔄 Actualiser.

      Téléphone en webcam par câble USB (poste fixe)

      1. Installez DroidCam (ou Iriun Webcam) sur le téléphone et son programme sur l'ordinateur ; utilisez un câble USB de données.
      2. Sur le téléphone, une seule fois : Paramètres › À propos du téléphone › touchez 7 fois Numéro de build, puis Paramètres › Système › Options pour les développeurs › Débogage USB.
      3. Branchez le câble, autorisez le débogage, ouvrez DroidCam sur le téléphone puis DroidCam Client sur l'ordinateur (bouton USB, Start).
      4. Dans la prise de vue, Utiliser la caméra 📱 « DroidCam », puis ★. Posez le téléphone sur un support et cliquez sur 📸 Capturer.

      Envoi par Wi-Fi local (photos prises en déplacement)

      1. Dans la prise de vue, ▶ Démarrer la réception (version Windows) : un code QR s'affiche. La première fois, autorisez TENKALA CARE sur les réseaux privés si Windows le demande.
      2. Le téléphone, connecté au même Wi-Fi, scanne le code : une page permet de Prendre une photo ou de Choisir dans la galerie.
      3. Les photos arrivent aussitôt dans les documents (copie dans Documents\TENKALA CARE SOFTWARE\Fichiers\telephone). Arrêt automatique après 20 minutes sans envoi.

      Les photos de patients relèvent du secret médical : consentement, pas de visage inutile, retirez-les une fois utilisées.

      22. Langue de l'interface (français / English)

      TENKALA CARE SOFTWARE s'utilise en français ou en anglais. Le choix se fait sur chaque appareil et s'applique aussitôt (le logiciel se recharge ; aucune donnée n'est perdue).

      1. Avant la connexion : sur l'écran de connexion, sous le bouton du manuel, cliquez sur 🌐 Français ou English.
      2. Une fois connecté : Aide › 🌐 Français ou Aide › 🌐 English.
      Ce qui est traduitMenus, boutons, formulaires, messages, tableaux, gestion du personnel et paie, comptabilité et fiscalité, interface du module de vaccination, documents imprimés depuis les fenêtres du logiciel (factures, attestations, bulletins, rapports) et le manuel (édition anglaise). Les termes médicaux suivent l'usage de l'OMS en anglais britannique (anaemia, haemoglobin, paediatrics, immunisation…). Les formulaires PDF officiels fournis par les autorités gardent leur texte d'origine.
      Ce qui reste tel que saisiLes données saisies sont enregistrées telles quelles et ne sont jamais modifiées. Le texte libre (noms, notes, observations) s'affiche tel que saisi ; les termes standard issus des listes du logiciel (diagnostics, produits, unités, statuts) s'affichent en anglais. En anglais, les informations sont enregistrées de la même façon qu'en français : une sauvegarde faite dans une langue se restaure dans l'autre. Le contenu des fiches In/formation et du lexique intégré reste en français dans cette version (textes médicaux validés).
      Documents officielsContrats, attestations et déclarations suivent le droit camerounais (Code du travail, Code général des impôts). La version anglaise est une traduction fidèle pour l'usage bilingue ; en cas de doute, la version française des textes officiels fait foi.

      23. Publiés (documents des campagnes)

      Documents › Publiés rassemble les documents utilisés pour les campagnes : affiches, dépliants, circulaires et notes de service, guides et protocoles, rapports, fiches techniques, présentations, photos, vidéos. Tout le monde peut les consulter ; les administrateurs et les personnes ayant accès aux Documents de gestion peuvent les publier, les modifier et les supprimer.

      Publier un document

      1. + Publier un document : titre, thème (Vaccination, Paludisme, VIH / IST, Nutrition…), type de document, campagne, année, source (MINSANTÉ, OMS, UNICEF, district…), public visé, mots-clés et description.
      2. 📂 Ajouter des fichiers : un ou plusieurs fichiers (PDF, images, Word, Excel, PowerPoint, vidéo, audio ; 50 Mo au plus chacun).
      3. Cliquez sur Publier. Le document apparaît aussitôt dans la liste.

      Retrouver un document

      La recherche fonctionne comme dans In/formation : tapez les premières lettres d'un mot du titre, de la campagne, des mots-clés, de la source, de l'année ou du nom du fichier (« roug » trouve « rougeole »), sans vous soucier des accents. Plusieurs mots affinent la recherche ; les mots trouvés sont surlignés. Les listes Thème, Type et Année filtrent les résultats.

      Consulter, télécharger, imprimer

      Cliquez sur un document : ses informations et ses fichiers s'affichent. 👁 Voir ouvre le fichier dans le logiciel (PDF, images, vidéo, audio) ; ⭳ Télécharger l'enregistre ; 🖨️ Imprimer imprime directement les PDF et les images. Les fichiers Word, Excel et PowerPoint se téléchargent puis s'ouvrent avec leur programme.

      Sauvegarde des fichiersLes informations des documents sont dans la sauvegarde générale (.json), mais pas les fichiers. Sous Windows, ils sont aussi copiés dans Documents\TENKALA CARE SOFTWARE\Fichiers\publies. Pour les passer sur un autre appareil : ⭳ Exporter les documents et leurs fichiers, puis, sur l'autre appareil, ⭱ Importer un export.
